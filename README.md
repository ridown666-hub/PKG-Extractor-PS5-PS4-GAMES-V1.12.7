# PKG Extractor — Arctic 
**Aplicação para Windows para trabalhar com pacotes PKG de PS5 e PS4.**  
Projeto de **RicardoStonePT**.

## Download

- **[Descarregar Portable (ZIP)](https://github.com/ridown666-hub/PKG-Extractor-PS5-PS4-GAMES-V1.12.7/releases/download/PKGExtractor/PKG_Extractor_Arctic_Fluid_Portable.zip)** — extrai a pasta completa e abre `INICIAR_PORTABLE.bat`.
- **[Descarregar EXE](https://github.com/ridown666-hub/PKG-Extractor-PS5-PS4-GAMES-V1.12.7/releases/download/PKGExtractor/PKG_Extractor_Arctic_Fluid.exe)** — executável da aplicação.

O botão **Code → Download ZIP** descarrega os ficheiros do repositório, não a aplicação compilada.

### Versão portátil

Não requer instalação da app. Usa `INICIAR_PORTABLE.bat` para guardar as definições na subpasta `Data`. Para transportar a app e as definições, copia a pasta inteira. Extrai para uma localização com permissão de escrita.

Abrir o EXE diretamente utiliza as definições normais do perfil Windows. O executável pode usar ficheiros temporários do Windows durante a execução. Caminhos de origem/destino podem precisar de ser selecionados novamente noutro computador.

O pacote conserva o EXE original. A integridade foi verificada por SHA256 e o ZIP foi validado automaticamente; esta edição portátil ainda não foi testada em execução no Windows.

## Utilização

1. Descarrega `PKG_Extractor_Arctic_Fluid.exe` nos ficheiros anexos da Release.
2. Abre a aplicação no Windows.
3. Escolhe **Extrair PKG** ou **PS4 PKG**, conforme o pacote.
4. Seleciona o ficheiro e a pasta de destino, e inicia a extração.

A compatibilidade depende do formato e das condições de acesso ao pacote. Não é garantido o suporte a todos os PKG.

## Interface

- Tema Arctic Fluid com navegação lateral.
- Página **PS4 PKG** com integração do motor PKGInstall.
- **Definições** e **Sobre** dentro da aplicação.
- Seleção de idioma na interface principal; alguns campos do motor PS4 podem permanecer em inglês.
