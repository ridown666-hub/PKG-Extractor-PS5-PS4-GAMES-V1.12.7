# PKG Extractor — Arctic Fluid

**Aplicação para Windows para trabalhar com pacotes PKG de PS5 e PS4.**  
Projeto de **RicardoStonePT**.

## Download

O executável será disponibilizado na secção [Releases](https://github.com/ridown666-hub/PKG-Extractor-PS5-PS4-GAMES-V1.12.7/releases).

**Estado da publicação:** página do projeto criada; carregamento do executável pendente. O botão **Code → Download ZIP** descarrega os ficheiros do repositório, não a aplicação compilada.

## Utilização

1. Descarrega `PKG_Extractor_Arctic_Fluid.exe` nos ficheiros anexos da Release, quando estiver disponível.
2. Abre a aplicação no Windows.
3. Escolhe **Extrair PKG** ou **PS4 PKG**, conforme o pacote.
4. Seleciona o ficheiro e a pasta de destino, e inicia a extração.

A compatibilidade depende do formato e das condições de acesso ao pacote. Não é garantido o suporte a todos os PKG.

## Interface

- Tema Arctic Fluid com navegação lateral.
- Página **PS4 PKG** com integração do motor PKGInstall.
- **Definições** e **Sobre** dentro da aplicação.
- Seleção de idioma na interface principal; alguns campos do motor PS4 podem permanecer em inglês.

## Reportar problemas

Abre uma [Issue](https://github.com/ridown666-hub/PKG-Extractor-PS5-PS4-GAMES-V1.12.7/issues) com a versão apresentada na app, a versão do Windows, os passos para reproduzir o problema e as linhas do erro. Não anexes jogos nem dados pessoais.
